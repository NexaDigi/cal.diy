# Historical Nexa operations records

Preserved on 2026-10-13 from the local ops/, deploy/ and BASELINE.md files.
These are historical records from August 2026, not evidence of current VPS
state. Paths, image tags, counts and pending tasks may be outdated.

The source snapshot is published in archive/nexa-0.0.3-source. See
../nexa-source-preservation.md for the publication and validation limits.
The Swarm template is ../nexa-swarm-stack.template.yml.

Private configuration copies are stored outside the source Git repository in
calcom/backups/private-config-20261013. Their hashes were compared with the
originals. They contain credentials and must not be uploaded to GitHub.
This local backup is not an independent off-machine backup.

The local Docker volumes for Nexa Agenda were left in place. No database dump
or current production deployment verification was performed for this archive.
